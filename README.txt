WORKSHOP REGISTRATION LAB STARTER

Student setup
1. Copy the folder named starter.
2. Rename the copy my-registration.
3. Open index.html in a browser.
4. Open index.html, styles.css and app.js in a text editor.
5. Follow the lab guide in order: HTML1, CSS1, CSS2, JS1, JS2, JS3 and JS4.
6. Save and reload the browser after each task.

The starter intentionally contains incomplete attributes, styles and JavaScript.
Use invented details and a practice password only. The page does not send or save data.
