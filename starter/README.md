## Project Description

Welcome to the Campus Create Workshop Registration project. This project is a simple and user-friendly workshop registration form designed for students to register for creative and practical workshops. It allows users to enter their personal details, select a workshop, choose a preferred date, indicate the number of seats they need, and preview their registration.

The project was developed using HTML, CSS, and JavaScript. It demonstrates the use of form controls, input validation, responsive design, JavaScript arrays and loops, and basic form logic. The available workshops include HTML Essentials, CSS Studio, and JavaScript Lab. The form also provides clear feedback when information is missing or entered incorrectly.

## How to Run

To run the project, download the repository to your computer and open the project folder. Open the `index.html` file in a web browser to view and use the workshop registration form.

The `index.html` file contains the structure of the registration page, `styles.css` contains the styling and responsive layout, and `app.js` contains the JavaScript functionality, including the workshop options, form validation, booking type, and registration feedback.
